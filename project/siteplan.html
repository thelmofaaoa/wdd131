Discover Tonga

Website Planning Document

1. Site Name

Discover Tonga

I chose the name "Discover Tonga" because the website will help visitors discover the beauty, culture, activities, and special places found throughout Tonga. The name is simple, memorable, and directly connected to the purpose of the website.

Possible domain name: discover-tonga.com

2. Site Purpose

The purpose of Discover Tonga is to provide useful information about Tonga for visitors and people who want to learn more about the country. The website will provide information about destinations, activities, culture, beaches, food, and things visitors can do while exploring Tonga.

The website will organize information in a simple way so that users can quickly find places to visit and activities to enjoy.

3. Scenarios

Potential visitors may ask questions such as:

  • What are some interesting places to visit in Tonga?
  • What activities can visitors do while they are in Tonga?
  • Where can I learn about Tongan culture and traditions?
  • What beaches and natural attractions can I visit?

4. Color Schema

The color scheme uses colors inspired by the ocean, sky, and tropical environment of Tonga.

Primary
#003B5C
Secondary

#EE9B00

Color Usage

  • Dark Blue (#003B5C): Header, footer, main headings, and navigation.
  • Teal (#005F73): Secondary headings and supporting design elements.
  • Gold (#EE9B00): Accents, borders, highlights, and important visual elements.
  • Light Gray (#F4F7F8): Main page background.

5. Typography

Georgia

Georgia will be used for the main headings and site title. It provides a traditional and welcoming appearance.

Arial

Arial will be used for paragraphs, lists, navigation, and other general content because it is easy to read on both desktop and mobile devices.
